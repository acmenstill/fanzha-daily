# 反诈信息日报 🛡️

参照 AIHOT（AI 行业动态聚合）网站的界面与结构，制作的**反诈信息日报**网站：
每日精选反电信网络诈骗动态、最新风险案例、高发类型拆解、风险预警与防护指南。

## 快速开始

直接用浏览器打开 `index.html` 即可使用（纯静态页面，无需服务器）。
也可以本地起服务：

```bash
cd 反诈信息日报
python3 -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765
```

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单页应用骨架（桌面侧边栏 + 移动端 TabBar） |
| `styles.css` | 样式表（深色/浅色主题，参照 AIHOT 设计语言，警蓝主色） |
| `data.js` | **全部内容数据**：资讯时间线、风险预警、反诈日报、十类高发电诈、防护指南 |
| `app.js` | 渲染与交互逻辑（hash 路由、收藏、搜索、主题切换、移动端适配） |
| `update.py` | **每日搜集更新脚本**（见下） |

## 页面（hash 路由）

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `#/` | 精选 | 编辑精选的资讯时间线（按日期分组） |
| `#/all` | 全部动态 | 全部资讯，支持类型筛选与关键词搜索 |
| `#/hot` | 热点榜 | 十类高发诈骗排行 + 近期高危案例 |
| `#/alerts` | 风险预警 | 紧急/重要风险提示 |
| `#/daily` | 反诈日报 | 每日反诈信息汇总 |
| `#/types` | 诈骗类型 | 公安部公布的十类高发电诈全拆解 |
| `#/guides` | 防护指南 | 核心号码、必备工具、防骗口诀、受骗处置 |
| `#/starred` | 收藏 | 本地收藏的资讯（星标按钮收藏） |

## 每日更新

`update.py` 会联网抓取公开新闻源（RSS），用反诈关键词过滤出最新条目，
去重后写入 `data.js` 并自动生成当日"反诈日报"。

```bash
python3 update.py            # 抓取后逐条确认
python3 update.py --auto     # 全自动（适合定时任务 / crontab）
python3 update.py --dry-run  # 只预览不写入
python3 update.py --manual   # 手动粘贴标题/摘要/链接录入
```

定时任务示例（每天 8 点自动更新）：

```bash
# crontab -e
0 8 * * * cd /path/to/反诈信息日报 && /usr/bin/python3 update.py --auto
```

### 手动新增条目

打开 `data.js`，在 `items: [` 数组**开头**复制一个已有对象并修改即可，例如：

```js
{
  id: "it-20260818-01",          // 唯一 id
  date: "2026-08-18", time: "08:00",
  source: "来源名称",
  type: "诈骗类型",               // 用于筛选分类
  risk: "high",                   // high | medium | low
  title: "标题",
  summary: "摘要",
  reason: "警示要点（选填）",
  selected: true,                 // true 会出现在精选页
  url: "https://...",             // 来源链接（选填）
  dups: []                        // 其他报道信源（选填）
}
```
